# Cooking Journal App - Codex Context

This is an existing offline browser-based cooking assistant and cooking log.

## Project goal

Build and maintain a single-page offline cooking journal app.

The app:
- runs from a single `index.html`
- uses vanilla HTML/CSS/JavaScript only
- has no server requirement
- has no build step
- has no external dependencies
- loads recipe data from `offline_cooking_journal_seed.json`
- saves user changes to `localStorage`
- can import/export JSON

## Important files

- `index.html` — the full app, including HTML, CSS, and JavaScript
- `offline_cooking_journal_seed.json` — recipe dataset

## Current app features

The app already includes:
- Netflix-style recipe category rows
- recipe cards
- recipe detail panels
- My List
- star ratings out of 5, including half-star increments
- recipe editing
- localStorage persistence
- JSON import
- JSON export
- normal recipe search
- My Kitchen ingredient matching

## Important rule

Do not rebuild the app from scratch unless explicitly asked.

Modify the existing `index.html`.

Preserve:
- current layout
- localStorage behaviour
- JSON import/export
- My List
- ratings
- editing
- recipe detail panels
- normal search
- existing JSON schema compatibility
